### **Dark Mode**
The system supports dark mode with inverted neutrals but preserved brand colors:
- Background → `0 0% 9%` (near black)
- Card → `0 0% 14%`
- Primary green brightens to `89 85% 45%`

---

| `radius-lg` | `0.5rem` |
| `radius-md` | `calc(0.5rem - 2px)` |
| `radius-sm` | `calc(0.5rem - 4px)` |

---

### **Shadows**
```css
/* Subtle card shadow */
.card-shadow {
  box-shadow: 0 2px 8px -2px hsl(0 0% 9% / 0.06), 
              0 4px 16px -4px hsl(0 0% 9% / 0.08);
}

/* Elevated card shadow (hover states) */
.card-shadow-elevated {
  box-shadow: 0 4px 12px -2px hsl(0 0% 9% / 0.08), 
              0 8px 24px -4px hsl(0 0% 9% / 0.12);
}
```

---

### **Interaction Patterns**

**Button hover lift:**
```css
.btn-hover-lift {
  transition: all 200ms;
}
.btn-hover-lift:hover {
  transform: translateY(-2px);
  box-shadow: 0 4px 6px -1px rgba(0,0,0,0.1);
}
```

### **Component Styling**

| Element | Style Notes |
|---------|-------------|
| **Buttons** | Rounded corners, primary green fill, white text, lift on hover |
| **Cards** | White background, subtle shadow, 0.5rem radius, 1px border on hover |
| **Inputs** | White background, gray border, green focus ring |
| **Badges** | Small, pill-shaped, muted backgrounds or colored for status |
| **Sidebar** | Off-white (`#FAFAFA`), green active indicator |

---

### **Layout Conventions**
- **Container max-width:** `1400px` (centered with `2rem` padding)
- **Grid system:** CSS Grid with responsive columns (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`)
- **Spacing:** Consistent use of Tailwind's 4px scale (`space-y-4`, `gap-6`, etc.)
